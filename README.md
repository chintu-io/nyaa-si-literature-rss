# Nyaa.si Literature RSS & Format Classifier

[![Build categorized RSS feeds](https://github.com/chintune/Nyaa-Literature-Format-Colors/actions/workflows/build-category-rss.yml/badge.svg)](https://github.com/chintune/Nyaa-Literature-Format-Colors/actions/workflows/build-category-rss.yml)

Separate Nyaa.si's mixed **Literature / English-translated** category into dedicated Manga, Novel, and Audiobook RSS feeds by inspecting the actual files inside each torrent. Also includes a Tampermonkey userscript that color-labels formats directly on Nyaa search results.

## Subscribe to the feeds

These are **live feed URLs**, not one-time downloads. Add the relevant URL to your RSS reader or a compatible torrent client's RSS feature:

| Feed | File-list rule | Subscribe URL |
|---|---|---|
| **Manga** | `.cbz` or `.cbr` | [feeds/manga.xml](https://raw.githubusercontent.com/chintune/Nyaa-Literature-Format-Colors/main/feeds/manga.xml) |
| **Novels** | `.epub` or `.pdf` | [feeds/novels.xml](https://raw.githubusercontent.com/chintune/Nyaa-Literature-Format-Colors/main/feeds/novels.xml) |
| **Audiobooks** | `.m4b` | [feeds/audiobooks.xml](https://raw.githubusercontent.com/chintune/Nyaa-Literature-Format-Colors/main/feeds/audiobooks.xml) |

**Feed freshness:** GitHub Actions checks the source Nyaa.si RSS feed every 30 minutes (at minutes 7 and 37 of each hour, UTC) and republishes the generated XML to these same URLs. The `<lastBuildDate>` in each XML indicates when the feed was generated. An RSS reader may check those URLs on its own polling schedule, so the time it displays can lag behind the latest build.

Source RSS: [Nyaa.si Literature / English-translated](https://nyaa.si/?page=rss&c=3_1&f=0)

## How automatic RSS generation works

The feeds are generated by **GitHub Actions + `scripts/build_feeds.py`**, not by the Tampermonkey userscript:

1. On its scheduled run, the workflow fetches Nyaa.si's source RSS, which currently provides a recent window of torrents.
2. For new or due-for-recheck entries, the Python builder fetches the torrent's detail page in the background and inspects its visible file list.
3. It records format classifications in `data/classification-cache.json`, then regenerates and commits the three RSS files under `feeds/`.
4. The RSS links above keep the same URL as the generated XML files are updated on the repository's `main` branch.

**The Tampermonkey userscript is a separate, optional browser feature.** It independently classifies and colors rows when you browse Nyaa.si. It does not run inside GitHub Actions and is not the program that generates the RSS feeds. The Python builder uses the same extension-based classification idea, implemented separately so it can run on GitHub Actions without a browser.

## Install the Tampermonkey userscript

1. Install Tampermonkey in your browser.
2. Open the [raw userscript](https://raw.githubusercontent.com/chintune/Nyaa-Literature-Format-Colors/main/nyaa-literature-format-colors.user.js). If automatic installation is not offered, copy it into a new Tampermonkey script and save.
3. Visit [Nyaa.si Literature / English-translated](https://nyaa.si/?f=0&c=3_1&q=).

The userscript makes background requests to torrent detail pages (it does not open tabs), colors the rows, and caches results in your browser. Use its **Retry UNKNOWN** control to retry entries it could not inspect.

## Classification rules

| Label | File extensions |
|---|---|
| **Manga** | `.cbz`, `.cbr` |
| **Novel** | `.epub`, `.pdf` |
| **Audiobook** | `.m4b` |
| **Mixed** | More than one format family appears |
| **Unknown** | No supported extension was found, or the file list could not be read |

The RSS builder assigns format families independently, so a mixed torrent can appear in more than one feed. The userscript shows a single **MIXED** badge when it finds multiple supported families.

## Freshness, coverage, and limitations

- The automation runs **twice per hour**, provided GitHub Actions is enabled and the scheduled workflow succeeds. Check the [Actions page](https://github.com/chintune/Nyaa-Literature-Format-Colors/actions/workflows/build-category-rss.yml) for the latest run and its status.
- Nyaa's source RSS is not a complete historical index. The builder can only discover torrents while they appear in its source window; this is not a backfill of every torrent ever uploaded.
- Each feed currently includes up to **200 matching entries**, and previously classified entries remain cached after leaving the source RSS window.
- A torrent whose file list is unavailable or contains none of the supported extensions will not enter a categorized feed until it can be classified.
- `.pdf` is counted as a novel/document format by rule, but some PDFs are manga scans. Extensions are a practical heuristic, not proof of a release's contents.
- Mixed torrents can appear in more than one feed. The source category is Nyaa.si's **Literature / English-translated** category only.
